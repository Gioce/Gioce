## Questions I like turning into code

- **Does a trading signal survive reality?** Out-of-sample testing, transaction costs, execution assumptions, and drawdown matter more than a pretty equity curve.
- **Can an AI agent be useful without unlimited access?** Local models, permission boundaries, auditable actions, and explicit approvals are part of the design.
- **Can a pipeline explain why it failed?** Validation, structured outputs, deterministic tests, and recovery paths are engineering features.
- **Can an automation remove work without hiding risk?** The objective is fewer manual steps *and* clearer control over exceptions.
